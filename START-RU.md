# Запуск и сдача проекта

1. Откройте папку `levaleva` в VS Code.
2. В терминале выполните `npm start` (нужен Node.js 20+).
3. Откройте http://127.0.0.1:4173. Устанавливать зависимости не нужно.
4. Проверка: `npm test`.
5. Создайте репозиторий `levaleva` на GitHub и загрузите содержимое папки. `index.html` должен лежать в корне.
6. Settings → Pages → Deploy from a branch → main → /(root) → Save.
7. Проверьте опубликованный сайт и сдайте ссылку на репозиторий до **22 ноября 2026, 23:59**.

Подробности и официальная ссылка на инструкцию GitHub — в README.md. Реальная регистрация и ID-porten отсутствуют по условиям задания. Погода демонстрационная. Новый тур сохраняется только в текущей вкладке браузера.
